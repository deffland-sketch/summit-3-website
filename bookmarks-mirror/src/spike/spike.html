Bookmarks Mirror: Phase 1 test

Three steps prove the extension can sign in, make a folder in your Drive, and point a shortcut at a colleague's Doc without touching the Doc itself. Run them in order.

1. Connect your Google account

A Google window opens and asks for permission. Read it before you approve: it should name your Cloud project and ask to see your Drive file list and manage only files this app creates.

2. Create the "Bookmarks mirror" folder

Makes one folder at the top of My Drive. If it already exists from an earlier run, it is reused.

3. Create a shortcut to a Doc you don't own

Open a Google Doc a colleague owns and shared with you, copy the address from the top of Chrome, and paste it here.
